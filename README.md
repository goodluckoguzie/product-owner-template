# Product Owner template

A one-page brief you fill in before a build. Research is part of the template, not a step you skip.

Open `index.html`, or the GitHub Pages site, and work in this order:

1. Five questions, including what is out of scope
2. Existing solutions, then a merged feature list
3. SWOT of those products
4. How you will build, and why
5. The first user and the value proposition
6. Working agreement and definition of done
7. Backlog, then one sprint
8. Download the pack into the new project's `docs/` folder

The page keeps your answers in the browser. Download when you want the markdown files.

## GitHub Pages

In the repository settings, set Pages to deploy from the `main` branch and the root folder. The site is `index.html`. No build step.
